## プロジェクト概要

**XRD Data Plotter** は、X線回折（XRD）の測定データのプロット作成および比較解析を自動化・効率化するために開発されたデスクトップGUIアプリケーションである。煩雑な複数データのスタック表示から、参照ピークの重畳、そして高精細なグラフ描画までをワンストップで完結させることができる。

## 開発の背景

材料研究におけるXRDデータの解析フローには、これまで**非効率性**と**反復作業の多さ**という大きな課題が存在していた。

- **グラフ調整の煩雑さ**: 複数の測定データを比較する際、グラフを縦にずらして配置したり、軸のスケールを対数（Log）に切り替えたりする作業を、汎用のグラフ作成ソフトで毎回手動で行うのは大きな時間的コストとなっていた。
- **相同定の手間**: 測定データに対して、既知の参照ピーク位置を重ねて描画し、結晶構造や相の同定を行う作業が直感的かつ迅速に行えなかった。

## 開発の目的と解決策

本アプリケーションは、上記の煩雑なプロット・解析フローを**一つの直感的なGUIアプリケーション上に統合**し、研究の生産性を劇的に向上させることを目的としている。

- **解析フローの直感化**: ドラッグ＆ドロップによる素早いデータ読み込みと、UI上のタブ切り替えによるシームレスな設定変更を実現。
- **グラフ即時出力**: スタック幅の調整や表示範囲の変更をリアルタイムにグラフへ反映し、高品質な画像として即座に様々な形式でエクスポート可能。
- **再現性と拡張性の確保**: アプリケーション設定の保存・読み込み機能により、過去のプロット状態を瞬時に復元できる体制を実現。

## 主な機能と特徴

### 1. 柔軟で高速なデータ読み込み

!データ読み込み

- **ドラッグ＆ドロップ対応**: エクスプローラーから複数の測定データファイルをリストボックスやグラフ領域に直接ドロップし、瞬時に一括読み込みが可能。
- **最近開いたファイル機能**: メニューバーから直近使用したファイル群へ素早くアクセス可能。
- **柔軟なリスト管理**: 読み込んだファイルの選択や表示切り替えを一元管理。

### 2. 高度なプロット設定と参照ピーク比較

<!-- ここにGIFを挿入：プロット設定タブでスタック表示の間隔を変更したり、参照ピークタブで表示/非表示を切り替えてグラフにピーク位置（垂直線）が重畳される様子 -->
!プロット設定・参照ピーク

- **スタック表示機能**: 複数のXRDパターンを比較しやすくするため、グラフを縦方向へ一定間隔で自動的にずらして表示（スタック幅の動的調整が可能）。
- **参照ピークのオーバーレイ表示**:
  - Pt(111) や Fe3O4(400) といった文献値などの参照ピーク（角度、色、線種）をリスト化し、任意のピークを選択して測定データ上に垂直線として重ね書きが可能。
  - ピーク位置を視覚的に比較できるため、相の同定作業を強力にサポートする。
- **解析ツール**: ピーク位置の特定や、格子定数計算（d値算出など）を補助するツール群を内包。

### 3. インタラクティブなグラフ描画

<!-- ここに画像を挿入：外観設定タブの詳細な項目（フォントサイズ、目盛り設定など）のクローズアップ -->
!グラフ詳細設定

- **詳細なスタイル制御**: Matplotlibを基盤とし、対数（Log）/線形（Linear）スケールの切り替え、軸のマイナーティック（補助目盛り）表示、フォントサイズ、線の太さ、凡例の配置など、学会誌の厳格なフォーマット要求に応えるカスタマイズが可能。
- **リアルタイムプレビューとデバウンス処理**: 数値スピンボックスや入力欄を変更した際、連続した再描画によるUIのフリーズを防ぐため、一定時間入力がない場合にのみ描画を更新する遅延処理（デバウンス処理）を実装。
- **モダンなUI/UX**: `sv_ttk` テーマを採用し、Windows 11にネイティブに馴染むフラットなデザインと、ダークモード / ライトモードの動的切り替えを提供。

### 4. データ管理と出力

<!-- ここに画像を挿入：エクスポートタブから保存する様子や、生成された画像の例 -->
!データ管理と出力

- **セッションの保存・復元**: 現在のプロット設定、ファイルのリスト、軸の範囲、参照ピークの設定などを `.json` 形式の設定ファイル（`xrd_app_config.json` など）として保存・読み込み可能。後日全く同じ体裁で作業を再開できる。
- **高解像度エクスポート**: 描画されたグラフを、任意のサイズ・フォーマット（PNG, PDFなど）で高画質な画像として保存。

### 設計の工夫
- **関心事の分離**: メインウィンドウ (`MainWindow`) は全体のUIとイベント管理に専念させ、状態管理 (`AppStateModel`)、ファイル操作 (`FileHandler`)、プロット処理 (`PlotHandler`)、設定管理 (`SettingsHandler`) をそれぞれ独立したクラスに分割し、密結合を防いでいる。
- **UIのモジュール化**: 多岐にわたる設定項目を扱うため、画面をタブごと（プロット設定、参照ピーク、外観、解析、エクスポート）に別のクラス・ファイルに分割し、画面構成の拡張性を高めている。
- **パフォーマンスへの配慮**: ユーザーの操作体験を損なわないよう、`schedule_update` メソッドによる描画のデバウンス処理を導入し、設定値を連続して変更してもアプリケーションがカクつかない快適な動作を確保。

## 導入と使用方法

本アプリケーションは、Python環境の構築が不要な **実行ファイル (.exe) による利用** が可能。

### 実行ファイル (.exe) による利用（一般ユーザー向け）

1. **ダウンロード**
   提供された実行ファイル群（またはZIPファイル）を取得し、任意のフォルダに配置。
2. **起動**
   フォルダ内の実行ファイル（`XRD解析プログラム.exe`）をダブルクリックしてアプリケーションを起動。

> **💡 Note: セキュリティ警告について**
> 初回起動時、WindowsのSmartScreen機能により「Windows によって PC が保護されました」という青い警告画面が表示される場合がある。**「詳細情報」をクリックし、右下に現れる「実行」ボタンを選択する**ことで、安全に起動可能。

### ソースコードからの実行（開発者向け）

**前提条件**: 実行環境に Python 3.12 がインストールされていること。

開発や機能のカスタマイズを行う場合は、以下の手順に従いソースコードから環境構築および起動を行う。

1. **リポジトリの取得**
   コマンドプロンプトやターミナルを開き、ソースコードをクローンしてディレクトリを移動する。
   ```bash
   git clone <https://github.com/yourusername/XRD_Analysis.git>
   cd XRD_Analysis
   ```

2. **仮想環境の作成と有効化**
   プロジェクト専用の独立したPython環境を構築。
   ```bash
   # 仮想環境を作成
   python -m venv env

   # 仮想環境を有効化する（Windowsの場合）
   env\Scripts\activate

   # 仮想環境を有効化する（macOS / Linuxの場合）
   source env/bin/activate
   ```

3. **必要なライブラリのインストール**
   ```bash
   pip install -r requirements.txt
   ```

4. **アプリケーションの起動**
   ```bash
   python main.py
   ```
