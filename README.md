## 概要

**XRD Data Plotter** は、Rigaku製装置が出力する `.ras` 形式のXRDデータを読み込み、プロット・解析・出力までを一画面で完結させるデスクトップGUIアプリケーションである。

研究現場でのXRD解析作業には、複数パターンの比較表示・参照ピークとの照合・ピークフィットといった繰り返し作業が多い。本アプリはそれらを直感的なGUI操作に集約することで、作業時間の大幅な短縮を目的としている。

---

## 主な機能

### データ読み込み
- **ドラッグ＆ドロップ**: エクスプローラーからファイルをリスト・グラフ領域に直接ドロップ
- **ファイル管理**: 複数ファイルの追加・削除・並べ替え（↑↓ボタン）
- **最近開いたファイル**: メニューバーから直近ファイルに素早くアクセス

### プロット設定
- **X軸範囲**: レンジスライダーまたはスピンボックスで調整（0〜180°）
- **強度しきい値**: しきい値以下を非表示 / 最小値に固定から選択
- **Y軸スケール**: Log / Linear の切り替え
- **スタック表示**: 複数パターンを縦方向にずらして重ね表示（間隔を動的に調整）
- **凡例**: 表示位置・枠線・イタリック・背景色を個別に設定

### 参照ピーク
- 最大10本のピークを登録（名称・角度・色・線種を個別設定）
- **プリセット収録**: γ-Fe₂O₃ / Fe₃O₄ / MgO / Pt / Cr（主要ピーク一覧から選択して自動入力）
- **SpinFilter プリセット**: スピンフィルタ向け複合プリセットをワンクリックで読込
- ラベルのフォントサイズ・Y位置・オフセットを設定可能

### 外観設定
- 軸ラベル・目盛り・フォント・線幅などを詳細にカスタマイズ
- グリッド表示 / 補助目盛り（X軸）の制御
- **テキストアノテーション**: グラフ上に任意のテキスト（数式・ギリシャ文字含む）を配置、位置はスライダーで調整

### 解析ツール
- **d値計算**: ピーク角度（2θ）とX線波長（デフォルト: Co Kα₁ = 1.78897 Å）からBragg則でd値を算出
- **格子定数計算**: d値と面指数 (h,k,l) から立方晶の格子定数 a を算出

### ピークフィット
- グラフ上をドラッグして対象範囲を選択すると自動でGaussianフィットを実行
- 結果テーブルに **2θ・FWHM・d値・結晶子サイズD（Scherrer式）・R²** を一覧表示
- **信頼性インジケータ**: R²≥0.99かつFWHM≥0.1° → ✓ / FWHM<0.1° → △ / R²<0.95 → ✗
- 選択行から格子定数計算パネルへd値を自動入力
- 結果をクリップボードにタブ区切りでコピー（Excel貼り付け対応）

### エクスポート・セッション管理
- **画像保存**: 幅・高さ・フォーマット（PNG / PDF / SVG）を指定してエクスポート
- **プレビュー**: 保存前に別ウィンドウで確認
- **設定の保存・読込**: 現在のファイル・プロット設定をJSONとして保存し後日復元
- **セッション復元**: 起動時に前回のセッションを復元するか確認ダイアログで選択可能（設定で有効/無効）

### UI全般
- **ダーク / ライトモード**: メニューバーからワンクリックで切り替え
- **デバウンス処理**: 連続入力時に不要な再描画を抑制し動作を軽快に維持

## セットアップ

### 実行ファイル（一般ユーザー向け）

1. 配布されている `XRD解析プログラム.exe` を任意のフォルダに配置
2. ダブルクリックで起動

> **初回起動時の警告について**  
> WindowsのSmartScreenが「Windows によって PC が保護されました」と表示する場合は、「詳細情報」→「実行」を選択すると起動できる。

### ソースコードから実行（開発者向け）

```bash
# 1. リポジトリをクローン
git clone https://github.com/yourusername/XRD_Analysis.git
cd XRD_Analysis

# 2. 仮想環境を作成・有効化（Windows）
python -m venv venv
venv\Scripts\activate

# 3. 依存ライブラリをインストール
pip install -r requirements.txt

# 4. 起動
python main.py
```

## 使い方

1. **ファイルを読み込む**  
   「ファイルを選択」ボタン または ファイルをウィンドウにドラッグ＆ドロップ

2. **プロットを調整する**  
   左パネルの各タブから設定を変更すると、グラフにリアルタイムで反映される

3. **参照ピークを重ねる**  
   「参照ピーク」タブでプリセットを選択するか、角度を手入力して重畳表示

4. **ピークをフィットする**  
   「ピークフィット」タブでフィットモードをONにし、グラフ上でピーク範囲をドラッグ選択

5. **グラフを保存する**  
   「エクスポート」タブでサイズと形式を指定して保存、または `ファイル > グラフを画像として保存`

## ディレクトリ構成

```
XRD_Analysis/
├── main.py                   # エントリーポイント
├── requirements.txt
├── assets/
│   └── XRD_ANALYSIS_ICON.ico
├── core/
│   ├── app_model.py          # アプリケーション状態（tkinter変数の一元管理）
│   ├── data_analyzer.py      # データ解析ロジック（パース・プロット・フィット）
│   └── config_manager.py     # 設定ファイルの読み書き
└── ui/
    ├── main_window.py        # メインウィンドウ・メニュー
    ├── style_manager.py      # カラーパレット・ボタンファクトリ
    ├── range_slider.py       # X軸レンジスライダーウィジェット
    ├── theory_dialog.py      # 理論・計算式の解説ダイアログ
    ├── tab_plot.py           # プロット設定タブ
    ├── tab_reference.py      # 参照ピークタブ
    ├── tab_appearance.py     # 外観設定タブ
    ├── tab_analysis.py       # 解析ツールタブ
    ├── tab_fit.py            # ピークフィットタブ
    ├── tab_export.py         # エクスポートタブ
    └── handlers/
        ├── file_handler.py   # ファイル操作
        ├── plot_handler.py   # グラフ描画
        ├── settings_handler.py # 設定保存・読込
        └── fit_handler.py    # ピークフィット操作
```

## 今後の展望

- **.ras 以外のフォーマット対応**: XRDML（PANalytical）など他社装置のデータ形式への対応
- **LorentzおよびPseudo-Voigt関数によるフィット**: Gaussianに加えてより汎用なピーク形状モデルの追加
- **バックグラウンド自動除去**: フィット精度向上のための前処理機能
- **大容量ファイルの非同期読込**: UIのフリーズを防ぐマルチスレッド処理の導入
