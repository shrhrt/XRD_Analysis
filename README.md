## プロジェクト概要

**XRD Data Plotter** は、Rigaku製装置が出力する `.ras` 形式のXRDデータを読み込み、プロット・参照ピーク比較・ピークフィット・グラフ出力までを一画面で完結させるデスクトップGUIアプリケーションである。

## 開発の背景

材料研究におけるXRD解析フローには、これまで**反復作業の多さと効率の悪さ**という課題が存在していた。

- **複数データの比較が煩雑**: 複数の測定パターンを比較する際、グラフを縦方向にずらして重ねる「スタック表示」や、対数スケールへの切り替えを、汎用ソフト（Excel・Ngraph等）で毎回手作業で行うことは大きな時間的コストだった。
- **相同定作業の非効率さ**: 測定データ上に既知の文献値（参照ピーク位置）を重ねて描画し、結晶構造や相の同定を行う作業が直感的に行えず、別途スプレッドシートで角度を管理することが一般的だった。
- **ピークフィットが手計算**: Scherrer式による結晶子サイズの見積もりや格子定数の算出を、Gaussianフィットの結果をもとに手計算で行うケースが多く、ミスや手間が生じていた。

## 開発の目的と解決策

本アプリケーションは、上記の煩雑な解析フローを**一つの直感的なGUIアプリケーション上に統合**し、研究の生産性を向上させることを目的としている。

- **解析フローの直感化**: ドラッグ＆ドロップによる素早いデータ読み込みと、タブ切り替えによるシームレスな設定変更を実現。スタック表示・参照ピーク重畳・ピークフィットを、キーボードをほぼ使わずに完結できる。
- **定量解析の自動化**: グラフ上でドラッグするだけでGaussianフィットを実行し、2θ・FWHM・d値・結晶子サイズD・R² を即座に算出してテーブルに一覧表示。格子定数の計算まで一連の操作で完了する。
- **再現性の確保**: アプリの設定（ファイルリスト・プロット設定・参照ピーク構成）をJSON形式で保存・読み込みでき、後日同じ体裁でグラフを再現できる。

### 2. 高度なプロット設定と参照ピーク比較

<!-- ここにプロット設定・参照ピーク重畳のスクリーンショットを挿入 -->
![プロット設定と参照ピーク](assets/images/plot_reference.png)

**プロット設定**
- **X軸範囲**: レンジスライダーまたはスピンボックスで0〜180°の範囲を直感的に設定。
- **強度しきい値**: しきい値以下のデータを「非表示」または「最小値に固定」から選択可能。
- **Y軸スケール**: Log / Linear をワンクリックで切り替え。
- **スタック表示**: 複数パターンを縦方向へ自動的にずらして重ね表示し、間隔をスライダーで動的に調整。
- **凡例**: 表示位置・枠線・イタリック体・背景色を個別設定可能。凡例名には数式（`$H_2O$`, `$\gamma$`）をTeX記法で記入できる。

**参照ピーク**
- 最大10本のピークを登録し、名称・角度・色・線種（実線/破線/点線/一点鎖線）を個別設定。
- **プリセット収録**: γ-Fe₂O₃ / Fe₃O₄ / MgO / Pt / Cr の主要回折ピークをメニューから選択して自動入力。
- **SpinFilter プリセット**: スピンフィルタ向け複合プリセットをワンクリックで一括読込。
- ピークラベルのフォントサイズ・Y位置・オフセットをUIから調整可能。

**外観設定**
- 軸ラベル・フォントサイズ・フォントファミリー・線幅・目盛り間隔・目盛りの向きをUIで詳細設定。
- グリッド線表示 / X軸補助目盛り（マイナーティック）の制御。
- **テキストアノテーション**: `$\boldsymbol{k}$//MgO[001]` のような数式・ギリシャ文字を含むテキストをグラフ上の任意位置に配置。X・Y位置はスライダーで調整。

### 3. ピークフィットと定量解析

<!-- ここにピークフィットのGIFを挿入 -->
![ピークフィット](assets/images/peak_fit.gif)

- **グラフ上でのドラッグ選択**: 「ピークフィット」タブでフィットモードをONにし、グラフ上でフィットしたい範囲をマウスドラッグで選択するだけで自動解析を実行。
- **Gaussianフィット**: SciPy の `curve_fit` を用いて線形バックグラウンド付きGauss関数をフィットし、以下を算出。

| 出力量 | 説明 |
| :--- | :--- |
| 2θ (°) | ピーク中心位置 |
| FWHM (°) | 半値全幅 |
| d 値 (Å) | ブラッグの法則 ($\lambda = 2d\sin\theta$) より算出。Co Kα₁ = 1.78897 Å を使用 |
| 結晶子サイズ D (Å) | Scherrer式 $D = 0.94\lambda / (\beta\cos\theta)$ より算出 |
| R² | フィットの決定係数 |

- **信頼性インジケータ**: 各フィット結果の品質を3段階で色分け表示。
  - ✓ 緑: R²≥0.99 かつ FWHM≥0.1°（高精度）
  - △ 黄: FWHM<0.1°（装置広がり補正が必要な可能性あり）
  - ✗ 赤: R²<0.95（フィット品質が低い）

- **格子定数計算**: 行を選択するとd値が自動入力され、面指数 (h,k,l) を入力することで立方晶の格子定数 $a = d\sqrt{h^2+k^2+l^2}$ を即算出。
- **クリップボードへのコピー**: 結果テーブルをタブ区切り（TSV形式）でコピーし、Excelに直接貼り付け可能。
- **解析ツール（別タブ）**: d値算出・格子定数計算を独立した入力フォームでも実行可能。

### 4. データ管理と出力

<!-- ここにエクスポートのスクリーンショットを挿入 -->
![エクスポート](assets/images/export.png)

- **高解像度エクスポート**: 描画グラフを任意の幅・高さ（inch指定）・フォーマット（PNG / PDF / SVG）で保存。保存前にプレビューウィンドウで確認可能。
- **設定の保存・読込**: 現在のファイルリスト・プロット設定・参照ピーク構成をJSONファイルとして保存し、後日完全に復元。
- **ダーク / ライトモード**: メニューバー「表示 → ダーク/ライトモードに切り替え」でテーマをリアルタイムに変更。
- **ログ記録**: 起動・ファイル読み込み・エラーの詳細を `~/.xrd_plotter/xrd_plotter.log` に記録し、トラブルシューティングを容易化。

## 技術スタックとアーキテクチャ

### 使用技術と選定理由

| カテゴリ | 使用技術 | 選定理由 |
| :--- | :--- | :--- |
| **開発言語** | Python 3.12+ | 科学計算ライブラリの充実さと、PyInstallerによる単体exe配布の容易さ |
| **GUIフレームワーク** | Tkinter / ttk | Python標準ライブラリ。外部依存ゼロで `.exe` 配布が可能 |
| **GUIテーマ** | sv_ttk 2.6.1 | Windows 11にネイティブに馴染む、フラットなモダンデザイン |
| **D&Dサポート** | tkinterdnd2 | Tkinterが標準で持たないドラッグ＆ドロップ機能を補完 |
| **データ可視化** | Matplotlib | 論文品質のSVG/PDF出力・TeX記法サポート |
| **数値計算** | NumPy | 測定データの高速ベクトル演算 |
| **ピークフィット** | SciPy | `curve_fit`（Gaussianフィット）と `find_peaks`（ピーク検出）を使用 |
| **パッケージング** | PyInstaller | 単体の `.exe` に固めてPython環境のないPCでも動作させるため |

### 設計の工夫

**連続入力でもUIが固まらないグラフ更新（デバウンス処理）**

スピンボックスやエントリーを変更するたびに `draw_plot()` を呼ぶとUIがフリーズする。`master.after(250, update_plot)` による250msのデバウンスを `schedule_update()` として抽象化し、全 `tk.Variable` のトレースに登録することで、最後の操作から250ms後に一度だけ再描画する方式を採用した。

**計算ロジックをGUIから完全に切り離す**

`core/data_analyzer.py` はGUI依存ゼロの純粋関数群で構成されている。Matplotlib の `Figure` オブジェクトと設定辞書のみを受け取り、tkinter への参照を一切持たない。この分離により、pytestでのユニットテストがGUIなしで実行でき、フィット計算の正確性を独立して検証できる。

**sv_ttk のボタン色制限への対処**

sv_ttk はボタン背景色をTCLエレメントレベルで上書きするため、`ttk.Style.configure("Primary.TButton", background=...)` が Windows 上で視覚的に反映されない。カスタム色が必要なボタンをすべて `tk.Button` に切り替え、`bg` / `activebackground` を直接指定することで確実に色を反映させた。色は `ui/style_manager.py` の定数（プライマリ `#00704A`・デンジャー `#C62828`）に集約し、全体の配色を一元管理している。

**鶏卵問題を回避するセッション復元**

「起動時にセッションを復元するか」の設定フラグは、セッションデータと同じファイルに保存するとデータを読む前にフラグを知ることができず矛盾が生じる。専用の `preferences.json` に `restore_on_startup` フラグのみを分離して保存することで、セッション本体（`xrd_app_config.json`）を読む前にフラグを確認できる設計とした。

## クイックスタート

> **動作環境: Windows 10 / 11** — Python 不要、ZIP を解凍してすぐ使える。

**ステップ 1 — ダウンロード**

GitHubの [Releases ページ](https://github.com/shrhrt/XRD_ANALYSIS/releases) から最新の ZIP をダウンロードして解凍する。

**ステップ 2 — 起動**

解凍したフォルダ内の `XRD解析プログラム.exe` をダブルクリック。

> **SmartScreen 警告が表示された場合**
> 「詳細情報」→「実行」の順に選択すると起動できる。初回のみ表示される。

**ステップ 3 — データを読み込む**

`.ras` ファイルをウィンドウにドラッグ＆ドロップするとグラフが即座に描画される。

**ステップ 4 — 参照ピークを重ねる**

「参照ピーク」タブ → 「物質を選択...」メニューから物質名を選ぶと、ピーク位置が自動でグラフに重畳される。

**ステップ 5 — ピークをフィットする**

「ピークフィット」タブ → 「フィットモード: ON」→ グラフ上でピーク範囲をドラッグ選択。

**ステップ 6 — グラフを保存する**

「エクスポート」タブ → サイズ・形式を指定して「グラフを保存」。

## 開発者向けセットアップ

**前提条件**: Python 3.12 以上がインストールされていること

```bat
:: リポジトリのクローン
git clone https://github.com/shrhrt/XRD_ANALYSIS.git
cd XRD_ANALYSIS

:: 仮想環境の作成・有効化
python -m venv venv
venv\Scripts\activate

:: 依存ライブラリのインストール
pip install -r requirements.txt

:: 起動
python main.py
```

**実行ファイルのビルド**

```bat
pyinstaller "XRD解析プログラム.spec"
```

ビルド成功後、`dist\XRD解析プログラム\XRD解析プログラム.exe` が生成される。

## 今後の展望

- **.ras 以外のフォーマット対応**: XRDML（PANalytical / Malvern Panalytical）など他社装置のデータ形式への対応
- **Lorentz / Pseudo-Voigt 関数によるフィット**: Gaussian に加えてより汎用なピーク形状モデルを追加し、非対称なピークにも対応
- **バックグラウンド自動除去**: 線形・多項式フィッティングによるバックグラウンドの前処理機能を追加し、フィット精度を向上
- **大容量ファイルの非同期読込**: マルチスレッド処理を導入し、大容量データ読み込み時のUIフリーズを防止
- **CI/CD パイプラインの構築**: GitHub Actions による pytest 自動実行・PyInstaller ビルドの自動化
